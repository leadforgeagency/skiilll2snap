Complete system design

        
Built in layers, so the AI never gets the final say

Presentation
A responsive vanilla web app, not a server-rendered Streamlit session. It owns drafts, previews, walkthrough position and the expert voice ID in browser state.
public/

        
HTTP boundary
Flask exposes one small JSON API. Vercel detects the app object in root app.py; every request is complete and independently executable.
app.py

        
Serverless service
Validates schemas and decoded file sizes, calls the existing modules, converts tuples to JSON, and turns binary audio/zip results into controlled responses.
web_service.py

        
Open-weight brain
Gemma Vision receives up to five in-memory image parts plus text and the voice transcript. It returns structured JSON and must flag unclear material instead of inventing it.
gemma_client.py

        
Voice layer
ElevenLabs Scribe transcribes, Flash or Multilingual TTS narrates, and Instant Cloning creates a voice only after consent. Removing the key disables voice, never the core.
voice.py

        
Deterministic core
Builds SKILL.md, checks frontmatter, names, sections and workflow, repairs broken files through the same builder, and packages the audit trail and audio.
skill_builder.py

        
Offline resilience
Two labelled sample extractions and text demo extraction mean a judge can test the real builder and validator even if venue Wi-Fi or a provider fails.
samples.py

        
Legacy local edition
The original Streamlit interface remains available for local demonstrations, but it is no longer the production entry point and is not required by Vercel.
streamlit_app.py

      


      

        
API contract

        

          
RoutePurposeImportant behaviour

          
            
GET /api/bootstrapStatus + samplesShows key presence only, never a secret value.

            
POST /api/extractSnap/text/voice → draftDecodes at most five images; transcribes audio before Gemma.

            
POST /api/buildEdited draft → SKILL.md + verdict + zipUses the same builder as every other interface.

            
POST /api/validateCheck any SKILL.mdReturns all thirteen checks, not just pass/fail.

            
POST /api/repairRepair a broken SKILL.mdPreserves workflow lines and rebuilds compliant structure.

            
POST /api/narrateFull skill narrationGemma translates first; ElevenLabs only speaks.

            
POST /api/speakOne walkthrough stepShort request, suitable for hands-free use.

            
POST /api/cloneInstant voice cloneBackend rejects the request unless consent is explicitly true.

          
        

      

    


    

      

        
Redeploy path

        
How this UI deploys and redeploys on Vercel

        
The repository root is the Vercel project root. There is no separate frontend repository and no Streamlit server to keep alive.

      

      

        
1
Import the GitHub repo
In Vercel choose Add New → Project → import leadforgeagency/skiilll2snap. Framework: Flask. Root directory: ./.

        
2
Add environment variables
Add GOOGLE_API_KEY and, optionally, ELEVENLABS_API_KEY and ELEVENLABS_VOICE_ID for Production and Preview.

        
3
Deploy
Vercel serves public/ through its CDN and runs app.py as Python Functions using root requirements.txt.

        
4
Redeploy automatically
Every push to main creates a new deployment. Use Deployments → Redeploy only when rebuilding the same commit, such as after changing an environment variable.

      

      

        Why the old Streamlit version could not simply be pointed at Vercel:
        
Streamlit expects a persistent Python process and live session connection. Vercel Functions are stateless request handlers. This version keeps the same product logic but moves state to the browser and each operation to a normal HTTP request, which is the architecture Vercel is designed to scale.

Full project detail

      

      

        

          
What is genuinely AI — and what is not

          
    
            
  • Gemma: image understanding, structured extraction and narration translation.
    • 
            
  • ElevenLabs: speech-to-text, text-to-speech and voice cloning.
    • 
            
  • Deterministic code: SKILL.md construction, validation, repair, source notes and zip layout.
    • 
            
  • Human: reviews unclear items and edits every field before export.
    • 
          

        

        

          
Failure behaviour

          
    
            
  • No Gemma key → labelled demo extraction still exercises the full pipeline.
    • 
            
  • No ElevenLabs key → voice disables; text creation, validation and zip remain available.
    • 
            
  • Provider error → API returns a clear warning instead of pretending success.
    • 
            
  • Oversized upload → browser downscales first; server enforces the Vercel ceiling again.
    • 
          

        

        

          
Security and privacy

          
    
            
  • API keys exist only as server environment variables.
    • 
            
  • Status endpoints expose booleans, never key fragments.
    • 
            
  • No database and no server-side upload archive.
    • 
            
  • Voice cloning is consent-gated in both UI and backend.
    • 
          

        

        

          
Known platform limits

          
    
            
  • Vercel request and response bodies are capped at 4.5 MB.
    • 
            
  • Very large original camera files are compressed before extraction.
    • 
            
  • Long Professional Voice Cloning is prepared in ElevenLabs, not trained inside this request flow.
    • 
            
  • Generated skills should be human-checked before use in safety-critical work.
    •
