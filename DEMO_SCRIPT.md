# 90-Second Demo Script — Snap2Skill

**[0:00 Hook]** "Every room here has a whiteboard full of knowledge that will be erased tonight. Every workshop, cafe, and lab in the world has the same problem — the expert knows how, and it's trapped in a photo nobody can use. Agent Skills can fix that, but nobody writes them by hand. So we made the camera write them."

**[0:20 Live snap]** Open the live Vercel site. Take a photo of ANY whiteboard / notebook in the venue (or upload the cafe whiteboard sample). Press **Generate the skill draft**.
"Open-weight Gemma 4 Vision just read that — not Gemini, Gemma, open weights, named in our README with its terms."

**[0:45 The proof]** Point to the green badge.
"Now the part no other generator shows you: our code validated the skill it just made — 13 checks, Agent Skills open standard, name matches folder, license, workflow, all of it. And look at the steps — only what was on that board. It marks unclear writing as unclear. It does not invent expertise."

**[1:00 The voice]** Press **Generate ElevenLabs narration**.
"The expert didn't just teach this — listen." [Skill plays in the expert-voice / library voice] "ElevenLabs narrates every skill, in seven languages, and that MP3 is inside the zip. And in Walkthrough mode, a trainee with dirty hands in a workshop hears it step by step, hands-free."

**[1:20 The payoff]** Download the zip, show the folder.
"Thirty seconds ago this was a photo. Now it's a skill that Claude Code, Cursor, Copilot — any agent that reads the open standard — can run forever. And Snap2Skill itself ships as a skill in our repo. It eats its own cooking."

**Close:** "Snap it before they erase it. Snap2Skill. MIT licensed, on GitHub."
